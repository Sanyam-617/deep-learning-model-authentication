## 1. Project Objective and Member 4 Responsibilities

### 1.1 Project Objective
The goal of this project is to authenticate deep learning models using a black-box, behavioral challenge-response mechanism. Rather than relying on fragile weight watermarks, digital signatures, or white-box inspection, the framework verifies model authenticity by presenting a deterministic set of synthetic challenge inputs and evaluating behavioral outputs against a pre-registered behavioral reference fingerprint.

### 1.2 Member 4 Responsibilities
As Member 4, the primary responsibilities are:
1. **Model Tampering Operators:** Implement controlled, reproducible post-training model modification procedures (Gaussian weight perturbation and magnitude pruning) to simulate real-world attacks, fine-tuning artifacts, compression, and parameter drift.
2. **Replacement Baseline Testing:** Evaluate an independently trained model architecture (different training seed) as an impostor baseline.
3. **End-to-End Evaluation Pipeline:** Safely load model checkpoints (including directory-based checkpoints via in-memory reconstruction) and integrate with Member 2's fingerprint extraction engine and Member 3's multi-metric authentication engine.
4. **Error Rate Analysis:** Formulate and compute False Acceptance Rate (FAR) and False Rejection Rate (FRR) with exact attempt accounting, without denominator distortion or artificial sample inflation.
5. **Visualization & Packaging:** Generate publication-ready degradation curves, decision space distributions, and empirical trade-off plots, concluding with a comprehensive and fully reproducible evaluation report.

## 2. Attack Evaluation Methodology

### 2.1 Preserved Upstream Components
The evaluation operates strictly on existing project artifacts without modification or retraining:
* **Target Architecture:** `CIFAR10CNN` from `train.py` (lightweight CNN with 4 convolutional layers, 2 max-pooling stages, and 2 fully connected classifier layers totaling 1,116,970 parameters).
* **Challenge Set:** 500 aligned, pre-processed challenge images stored in `data/challenges/challenge_set.pt` (generated by Member 1).
* **Reference Fingerprint:** `data/fingerprints/reference_fingerprint.json` containing predicted labels, confidence scores, and probability vectors for the 500 challenges (generated by Member 2).
* **Authentication Engine:** `ModelAuthenticator` from `src/authentication/authenticator.py` (developed by Member 3).

### 2.2 Member 3 Baseline Authentication Rule
Member 3's authentication decision evaluates a strict conjunction of three distinct behavioral metrics:
1. **Prediction Agreement ($A$):** Top-1 label match ratio across the 500 challenges:
   $$A = \frac{1}{N} \sum_{i=1}^N \mathbb{I}[y_{\text{ref}}^{(i)} == y_{\text{test}}^{(i)}] \in [0.0, 1.0]$$
   Baseline threshold: $A \ge 0.85$.
2. **Mean Cosine Similarity ($C$):** Geometric alignment of probability vectors:
   $$C = \frac{1}{N} \sum_{i=1}^N \frac{\mathbf{u}_i \cdot \mathbf{v}_i}{\max(\|\mathbf{u}_i\|_2 \|\mathbf{v}_i\|_2, \epsilon)} \in [-1.0, 1.0]$$
   Baseline threshold: $C \ge 0.90$.
3. **Mean Kullback-Leibler (KL) Divergence ($D_{KL}$):** Information-theoretic distribution divergence:
   $$D_{KL} = \frac{1}{N} \sum_{i=1}^N \sum_{k=1}^K P_i(k) \ln \frac{P_i(k)}{Q_i(k)} \in [0.0, \infty)$$
   Baseline threshold: $D_{KL} \le 0.15$ (lower indicates higher fidelity; $0.0 = \text{identical}$).

$$\text{Authenticated} = (A \ge 0.85) \land (C \ge 0.90) \land (D_{KL} \le 0.15)$$

### 2.3 Strict Memory & Storage Isolation
To protect original models and checkpoints:
* `models/original_model.pth` is an unpacked directory-based PyTorch checkpoint. It is reconstructed in-memory via an internal `io.BytesIO` zip buffer without writing to disk.
* All tampering operators operate strictly on an independent `copy.deepcopy()` of the model in RAM. Source model weights remain 100% unaltered.

## 3. Genuine Baseline and Replacement-Model Evaluation

### 3.1 Positive Control (Genuine Original Model)
The genuine original model (`models/original_model.pth`) was evaluated on the 500 challenges:
* **Prediction Agreement:** $1.0000$ (500 / 500 matches)
* **Cosine Similarity:** $1.0000$ ($0.99999998$)
* **KL Divergence:** $0.000000$ ($3.98 \times 10^{-8}$ nats)
* **Baseline Threshold Evaluation:** All three metrics pass.
* **Authentication Decision:** **AUTHENTIC (True Acceptance)**.

### 3.2 Replacement / Impostor Baseline (`different_seed_model.pth`)
To simulate an adversary attempting to pass an independently trained, functionally competent model of identical architecture, the different-seed model (trained with seed 123 instead of seed 42) was evaluated:
* **Prediction Agreement:** $0.7380$ (369 / 500 matches) $\implies$ **FAILS** ($< 0.85$).
* **Cosine Similarity:** $0.9122$ $\implies$ PASSES ($\ge 0.90$).
* **KL Divergence:** $0.225192$ nats $\implies$ **FAILS** ($> 0.15$).
* **Authentication Decision:** **REJECTED (True Rejection)**.

> **Key Finding on Metric Non-Equivalence:** Cosine similarity alone ($0.9122$) would have falsely accepted the replacement model under the 0.90 threshold. The multi-metric conjunction successfully rejected the impostor because top-1 prediction agreement ($0.7380$) and KL divergence ($0.2252$) detected significant behavioral divergence.

## 4. Gaussian Weight Perturbation Experiments

Weight perturbation models parameter drift, noisy quantization, or adversarial jitter by injecting independent zero-mean Gaussian noise into all 2D convolutional and linear layer weights:
$$W' = W + \mathcal{N}(0, (\sigma \cdot \text{std}(W))^2)$$
Scaling the noise standard deviation relative to each layer's parameter standard deviation $\text{std}(W)$ ensures balanced perturbation across layers.

Experiments were conducted across six standard deviations ($\sigma \in \{0.001, 0.005, 0.01, 0.02, 0.05, 0.10\}$) and three deterministic random seeds ($42, 43, 44$), yielding **18 unique model variants**:

* **$\sigma = 0.001$ (0.1% layer std):** Imperceptible shift. Agreement: $1.0000$, Cosine: $1.0000$, KL: $\sim 4.0 \times 10^{-6}$. All pass.
* **$\sigma = 0.005$ (0.5% layer std):** Agreement: $0.9900 - 0.9980$, Cosine: $\ge 0.9999$, KL: $\sim 1.0 \times 10^{-4}$. All pass.
* **$\sigma = 0.01$ (1.0% layer std):** Agreement: $0.9820 - 0.9880$, Cosine: $\ge 0.9997$, KL: $\sim 4.0 \times 10^{-4}$. All pass.
* **$\sigma = 0.02$ (2.0% layer std):** Agreement: $0.9660 - 0.9740$, Cosine: $\ge 0.9991$, KL: $\sim 1.5 \times 10^{-3}$. All pass.
* **$\sigma = 0.05$ (5.0% layer std):** Agreement: $0.9280 - 0.9500$, Cosine: $\ge 0.9950$, KL: $\sim 8.9 \times 10^{-3}$. All pass.
* **$\sigma = 0.10$ (10.0% layer std):** Agreement: $0.8580 - 0.9020$, Cosine: $\ge 0.9794$, KL: $\sim 3.3 \times 10^{-2}$. All pass.

**Vulnerability Insight:** Convolutional neural networks exhibit substantial parameter redundancy. Even when weights are perturbed by 10% of their standard deviation, prediction agreement on the 500 challenges remains $\ge 85.80\%$, satisfying Member 3's baseline threshold ($0.85$) and resulting in 18 false acceptances out of 18 attempts.

## 5. Magnitude Pruning Experiments

Unstructured magnitude pruning simulates network compression, parameter zeroing, and sparsity-inducing post-processing. For each convolutional and linear layer, weights below the sparsity quantile threshold are zeroed out:
$$W_{ij}' = \begin{cases} 0, & \text{if } |W_{ij}| < \text{quantile}(|W|, s) \\ W_{ij}, & \text{otherwise} \end{cases}$$

Evaluated across six sparsity levels ($s \in \{0.05, 0.10, 0.20, 0.35, 0.50, 0.75\}$), yielding **6 unique model variants**:

* **$s = 0.05$ (5% zeroed):** Agreement: $0.9820$, Cosine: $0.9998$, KL: $0.000401$. **Pass** (False Acceptance).
* **$s = 0.10$ (10% zeroed):** Agreement: $0.9840$, Cosine: $0.9994$, KL: $0.001179$. **Pass** (False Acceptance).
* **$s = 0.20$ (20% zeroed):** Agreement: $0.9240$, Cosine: $0.9912$, KL: $0.016588$. **Pass** (False Acceptance).
* **$s = 0.35$ (35% zeroed):** Agreement: $0.8480$, Cosine: $0.9624$, KL: $0.075756$. **REJECTED** (True Rejection; Agreement drops below 0.85).
* **$s = 0.50$ (50% zeroed):** Agreement: $0.7120$, Cosine: $0.8979$, KL: $0.241602$. **REJECTED** (True Rejection; all 3 metrics fail).
* **$s = 0.75$ (75% zeroed):** Agreement: $0.1620$, Cosine: $0.5439$, KL: $1.265280$. **REJECTED** (True Rejection; catastrophic collapse).

**Pruning Boundary:** The framework tolerates up to 20% sparsity. Pruning at 35% or above immediately trips the authentication engine, yielding 100% rejection on severe pruning.

## 6. Error Rates: Definitions, Denominators, and Final Values

### 6.1 Definitions and Mathematical Formulas
* **False Rejection Rate (FRR):** The proportion of genuine model attempts that are falsely rejected:
  $$\text{FRR} = \frac{\text{False Rejections among Genuine Attempts}}{\text{Total Genuine Attempts}} = \frac{N_{\text{FR}}}{N_{\text{genuine}}}$$
* **False Acceptance Rate (FAR):** The proportion of unauthorized model attempts that are falsely authenticated:
  $$\text{FAR} = \frac{\text{False Acceptances among Unauthorized Attempts}}{\text{Total Unauthorized Attempts}} = \frac{N_{\text{FA}}}{N_{\text{unauthorized}}}$$

## 10. Limitations

1. **Single Genuine Checkpoint ($N=1$):**
   * Only one trained checkpoint for the genuine model was available in the repository. While evaluating this checkpoint yielded zero false rejections ($\text{FRR} = 0.00\%$), this represents an empirical check on a single positive control and does **not** prove a population-wide FRR of zero across varied hardware, floating-point libraries, or training runs.
2. **Fixed Challenge Set (500 Samples):**
   * The challenge set comprises 500 fixed CIFAR-10 challenge images. Performance reflects this specific challenge distribution.
3. **Absence of Fine-Tuning Experiments:**
   * Fine-tuning was intentionally omitted because the full CIFAR-10 training set is not present in the workspace, and downloading external data was prohibited by the project's strict minimal-change and preservation rules.
4. **Finite Sample Trade-Off Resolution:**
   * With 25 unauthorized models and 1 genuine model, the trade-off curve displays discrete step transitions rather than a continuous distribution.

## 11. Final Conclusions & Future Work

### 11.1 Conclusion
The Member 4 tampering and evaluation deliverables demonstrate that the behavioral challenge-response paradigm is:
* **Decisive Against Architectural Impostors:** Replacement models with identical architecture but different random seeds are completely rejected ($\text{FAR} = 0.00\%$).
* **Robust Against Severe Pruning:** Pruning levels of 35% or higher are rejected 100% ($\text{FAR} = 0.00\%$).
* **Sensitive to Threshold Tuning for Parameter Perturbations:** Under baseline development thresholds ($A \ge 0.85$), standard CNN parameter redundancy allows Gaussian noise up to $\sigma = 0.10$ to pass. Stricter thresholds ($A \ge 0.98 - 0.99$) significantly enhance sensitivity to subtle weight tampering without degrading genuine acceptance.

### 11.2 Recommended Future Work
1. **Multi-Seed Genuine Training:** Train multiple independent instances of the genuine model (same seed/data split) across different hardware architectures to establish an empirical distribution for FRR.
2. **Fine-Tuning & Quantization Benchmarks:** Incorporate post-training 8-bit integer quantization (INT8) and low-learning-rate fine-tuning on downstream domain splits.
3. **Automated EER Calibration:** Formally calibrate the operational Equal Error Rate (EER) threshold in Phase 5 using joint multi-dimensional ROC surfaces across Agreement, Cosine, and KL Divergence simultaneously.
